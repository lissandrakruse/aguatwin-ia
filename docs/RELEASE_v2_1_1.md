# ÁguaTwin IA v2.1.1

Versão de pesquisa com inventário hidroquímico público e preparação de depósito científico.

## Alterações

- Congelamento de 130 registros químicos da camada pública SIAGAS da Paraíba.
- Auditoria das 13 fichas de Cabaceiras, com sólidos dissolvidos totais e dados incompletos de íons.
- CSV, fontes, hashes e script reproduzível de auditoria.
- Página de consulta dos dados químicos acessível pelo simulador.
- Documentação dos critérios de limpeza e da cartografia de 2019 na escala 1:500.000.
- Metadados de citação e instruções para depósito no Zenodo.

Nenhuma das 13 fichas tem CE, Na, Ca e Mg com identificação e data suficientes para revisão conjunta. Não foram recalculados modelos, métricas ou probabilidades de aptidão agrícola.

O manuscrito v2.2/v2.3 e o repositório v2.1 descrevem avaliações diferentes. Este release não atribui ao repositório resultados de modelos ausentes de seu código.

## Verificação

Auditoria reproduzida com a amostra congelada; contagens e identificadores conferidos. Conversão de unidades e tratamento de ausências verificados. Os testes históricos dos modelos não foram executados novamente, pois modelos e dados de treino não foram alterados.

## Zenodo

O depósito e a atribuição de DOI ainda não foram realizados. Use os arquivos do release e mantenha a atribuição ao SGB para dados públicos.
